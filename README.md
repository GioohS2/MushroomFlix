## 🔍 Visão Geral
Este projeto é uma aplicação web simplificada desenvolvida com o objetivo principal de estudar e testar a integração com servidores externos, utilizando especificamente a YouTube Data API v3.
A plataforma funciona como um client-side customizado para consumo de mídia, permitindo que o usuário busque e assista a vídeos hospedados no YouTube diretamente por uma interface própria, limpa e livre de distrações.
---

## ✨ Funcionalidades
• Player responsivo: Adaptável a telas de celulares, tablets e computadores.
• Controles básicos: Botões de reproduzir/pausar, pular 10 segundos, controle de volume, tela cheia e ajuste de velocidade.
• Streaming adaptativo: Ajuste automático da qualidade do vídeo (ex: 480p, 720p, 1080p) baseado na velocidade da internet do usuário.
• Legendas e múltiplos áudios: Suporte a arquivos de legenda (SRT/VTT) e troca de idioma.

3. Instale as dependências:
